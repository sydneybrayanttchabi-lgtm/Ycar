## 2026-08-20 - Accessible Tab Navigation Pattern for Custom Tab Interfaces
**Learning:** In custom React tab components without an underlying UI library (such as Headless UI or Radix), custom tab buttons lack critical ARIA roles (`role="tablist"`, `role="tab"`, `role="tabpanel"`, `aria-selected`, `aria-controls`, and `aria-labelledby`) and visible keyboard focus rings. Adding these semantics and `focus-visible:ring-2` allows screen readers to announce tab relationships and current selection state while giving keyboard users clear focus navigation feedback without visual disruption on click.
**Action:** Always verify custom tab navigation interfaces provide `role="tablist"` on the list container, `role="tab"` with `aria-selected` and `aria-controls` on the tab buttons, and `role="tabpanel"` with `aria-labelledby` on the active content section.
