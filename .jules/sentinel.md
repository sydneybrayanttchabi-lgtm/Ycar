## 2026-08-20 - URL Scheme Validation for Untrusted CSV Link Attributes
**Vulnerability:** External dealer link (`Lien_Vendeur`) in the vehicle CSV was rendered directly as `<a href={selectedCar.Lien_Vendeur}>` and 3D model URL (`Modele_3D_URL`) was passed to `<model-viewer src="...">` without scheme validation, allowing potential XSS via `javascript:` or `data:` URLs if malicious or malformed CSV entries were loaded.
**Learning:** In client-side single-page applications reading CSV or external tabular datasets into DOM link anchors or custom web components, relying solely on falsy or non-empty string checks is insufficient because arbitrary URI schemes can execute script or load arbitrary content in the user's browser context.
**Prevention:** Always validate external URL schemes using URL parsing (`new URL(...)`) and explicitly whitelist only allowed network protocols (`http:` and `https:`) before passing them to `href` or `src` attributes. Provide safe fallbacks or disabled states when invalid or missing.
