## 2025-05-18 - ModelViewer DOM XSS via innerHTML Template Interpolation
**Vulnerability:** `ModelViewerComponent` in `app.py` directly interpolated untrusted CSV data (`src` and `alt` properties) into a template string passed to `containerRef.current.innerHTML`. Crafting malicious HTML/JS payloads in the CSV fields allowed DOM-based XSS execution. Additionally, unvalidated URI schemes in `src` could trigger malicious protocols.
**Learning:** React components wrapping Web Components or third-party custom elements (`<model-viewer>`) often resort to `innerHTML` when custom elements aren't immediately compatible with standard JSX types or runtime behavior, inadvertently bypassing React's built-in XSS protections.
**Prevention:** Construct DOM nodes via `document.createElement` and set attributes using `setAttribute` or element properties rather than `innerHTML`. Always validate URI schemes against an allowlist (e.g. `https:`, `http:`, or relative paths) before setting asset sources.
